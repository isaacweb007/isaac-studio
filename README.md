# 아이작 스튜디오 — ISAAC STUDIO

AI 광고영상 제작 스튜디오 랜딩페이지.

**광고 한 편, 7일.** 기획과 연출은 사람이, 촬영은 AI가 합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 랜딩페이지 (단일 파일 · 외부 의존성은 Google Fonts만) |
| `reels/` | 납품작 영상 + 포스터 |
| `refs/` | 숏폼 포트폴리오 영상 + 썸네일 |

## 기능

- 포트폴리오 **35편** · 업종 필터 9종 (전체·F&B·뷰티·테크·패션·라이프스타일·주얼리·그래픽·앱)
- **7개 국어** — 한국어 · English · Tiếng Việt · 日本語 · 简体中文 · Bahasa Indonesia · Bahasa Melayu
  (브라우저 언어 자동 감지 · 선택 기억 · 언어별 디스플레이 폰트 자동 교체)
- 영상 **지연 로딩** — 초기 로드 시 mp4 요청 0건, 재생 시점에만 소스 주입
- 라이트/다크 테마 자동 대응
- 모바일 최적화 (햄버거 메뉴 · 필터 가로 스크롤 · 터치 기기 hover 차단)
- `prefers-reduced-motion` 존중

## 로컬 실행

```bash
python3 -m http.server 8000
```

## 라이선스

영상 저작권은 아이작 스튜디오 및 각 클라이언트에 있습니다. 무단 사용 금지.
